# Plugins

本セクションは、プリセットが束ねる 4 つの Eleventy プラグインの内部設計と応用ケースを扱います。「なぜこう作ったか」と「どう動くか」に閉じ、日常の書き方は [Preset の規約](/ja/preset/) を参照してください。

## プラグイン一覧

- [`@tuqulore-inc/eleventy-plugin-preact`](/ja/plugins/eleventy-plugin-preact/): JSX / MDX を Eleventy のテンプレートとして扱い、Preact でサーバサイドレンダリングします。
- [`@tuqulore-inc/eleventy-islands`](/ja/plugins/eleventy-islands/): Partial Hydration を担い、`.client.*` を bundle して `<is-land>` で hydrate します。Preact 用のアダプタと esbuild 用のバンドラをサブパスで提供します。
- [`@tuqulore-inc/eleventy-plugin-postcss`](/ja/plugins/eleventy-plugin-postcss/): PostCSS を Eleventy のテンプレート形式として登録し、Tailwind CSS などのプラグインを回します。
- [`@tuqulore-inc/eleventy-collections`](/ja/plugins/eleventy-collections/): collection のディレクトリに置いたスキーマから、ビルド時の検証と `eleventy.collections` の型を導きます。

4 つとも独立してインストールでき、プリセットを介さずに他の Eleventy プロジェクトへ持ち込めます。

このほか、`eleventy` シングルトンと型は [`@tuqulore-inc/eleventy-data`](/ja/plugins/eleventy-data/) が持ちます。Eleventy プラグインではなく、レンダラとテンプレートが共有するパッケージです。

## API リファレンスと拡張

- 各プラグインの API (オプション、export される関数) は、パッケージの README を参照してください。
- プリセットに別のプラグイン (例: RSS、Syntax Highlight) を追加したい場合は、`preset()` に extend 関数を渡して `eleventyConfig.addPlugin` を呼びます。詳細は `@tuqulore-inc/eleventy-preset` の README を参照してください。
